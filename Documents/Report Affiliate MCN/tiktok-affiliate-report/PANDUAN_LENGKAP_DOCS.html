BAGIAN 1 — Ambil Cookie TikTok

Cookie dibutuhkan agar scraping bisa mengambil data Views/Likes/Comments dengan akurat.

Cara pakai ekstensi (paling mudah):
  1. Install ekstensi Chrome: Cookie-Editor (cari di Chrome Web Store)
  2. Buka tiktok.com → login akun TikTok kamu
  3. Klik ikon ekstensi Cookie-Editor di toolbar browser
  4. Klik tombol Export → copy semua teks yang muncul
  5. Buka http://72.62.244.186:8082/settings
  6. Paste di kolom TikTok Cookies → klik Simpan
⚠️ Cookie hanya perlu diisi sekali. Jika scraping mulai gagal, ulangi langkah ini karena cookie sudah expired.

BAGIAN 2 — Upload File Excel

  1. Buka http://72.62.244.186:8082
  2. Klik Pilih File → pilih file Excel kamu (.xlsx)
  3. Klik Upload
  4. Tunggu muncul notifikasi hijau "Parse selesai"
✅ Pastikan file Excel punya kolom: USERNAME, LINK ACC, AVG GMV/MONTH, dan kolom link video seperti UPDATE VT [FOLLOWUP]

BAGIAN 4 — Scraping Data Engagement

Setelah Apply Mapping, scroll ke bawah ke bagian Data Engagement.

  1. Klik Scrape 20 Creator untuk test dulu
  2. Tunggu progress bar berjalan — estimasi ~4–6 menit untuk 20 creator
  3. Jika hasilnya bagus (ada angka Views/Likes), klik Scrape Semua
  4. Tunggu sampai selesai — jangan tutup browser

BAGIAN 6 — Generate Laporan (PPT / PDF)

  1. Scroll ke bawah ke bagian Generate Laporan
  2. Pilih format: PPT atau PDF (atau keduanya)
  3. Klik tombol Generate
  4. Tunggu proses selesai (biasanya 10–30 detik)
  5. Klik Download PPT atau Download PDF
✅ File akan otomatis terdownload ke komputer kamu.

BAGIAN 7 — Copy ke Google Docs / Word

Untuk PPT → Google Slides:

  1. Buka slides.google.com
  2. Klik Blank presentation
  3. Klik menu File → Import slides
  4. Upload file .pptx yang sudah didownload
  5. Pilih semua slide → klik Import slides

Untuk PDF → Google Docs:

  1. Buka drive.google.com
  2. Upload file PDF
  3. Klik kanan file PDF → Open with → Google Docs
  4. Google Docs akan otomatis convert PDF ke teks yang bisa diedit
