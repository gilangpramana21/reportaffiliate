Privacy Policy

Last updated: April 2026

1. Information We Collect

The MCN Affiliate Report Tool collects the following information through TikTok API integration:

  • TikTok creator profile information (username, bio, verification status)
  • Creator statistics (follower count, video count, likes count)
  • Public video list and metadata

This information is accessed only when authorized users of the tool initiate a data retrieval request.

2. How We Use Information

Information collected through TikTok APIs is used exclusively for:

  • Generating internal affiliate campaign performance reports
  • Evaluating creator performance for MCN brand clients
  • Tracking content compliance and engagement metrics
3. Data Storage

Creator data retrieved from TikTok is stored locally on the MCN agency's internal server. Data is retained only as long as necessary for reporting purposes and is not shared with external parties.

4. TikTok Data

We access TikTok user data in accordance with TikTok's Platform Policies and only with proper authorization. We do not store TikTok access tokens beyond their expiration period. Creator data is accessed only for the purpose of generating performance reports.

5. Data Sharing

We do not sell, trade, or share creator data with third parties. Data is used solely for internal MCN agency reporting purposes.

6. Security

We implement appropriate security measures to protect data stored in our system. Access to the tool is restricted to authorized MCN agency staff only.

7. Creator Rights

Creators whose data is accessed through TikTok APIs have the right to request information about how their data is used. Please contact the MCN agency administrator for such requests.

8. Contact

For privacy-related questions or requests, please contact the MCN agency administrator.
