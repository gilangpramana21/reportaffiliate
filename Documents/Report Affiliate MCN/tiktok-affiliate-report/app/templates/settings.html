Cookie TikTok digunakan untuk mengambil data views, likes, dan comments creator secara otomatis. Cookie perlu diperbarui setiap ~30 hari.

Cara mendapatkan cookie TikTok:
  1. Buka tiktok.com di Chrome dan login
  2. Tekan F12 → tab Application → Cookies → https://www.tiktok.com
  3. Install extension EditThisCookie atau Cookie-Editor
  4. Klik export → copy semua cookie dalam format JSON atau string
  5. Paste di field di bawah
